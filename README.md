# 📺 Teleprompt TV

Um teleprompter simples feito em HTML para exibir textos em tela cheia, ideal para leitura em TVs, gravações de vídeo ou apresentações.

---

## ✨ Sobre o projeto

O **Teleprompt TV** é uma aplicação leve que permite digitar ou colar um texto e exibi-lo em formato de teleprompter, rolando automaticamente na tela.

Perfeito para quem precisa ler roteiros de forma prática, sem perder o foco — como em vídeos, lives, palestras ou apresentações.

---

## 🚀 Funcionalidades

- 📝 Campo para digitar ou colar texto
- 📺 Exibição em tela cheia (ideal para TV ou monitor grande)
- 🔄 Rolagem automática do texto
- 🎯 Interface simples e direta
- ⚡ Sem necessidade de instalação (funciona direto no navegador)

---

## 🖥️ Como usar

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/BresoDEV/Teleprompt-TV.git
   ```

2. Abra o arquivo `index.html` no navegador

3. Digite ou cole o texto desejado

4. Inicie o teleprompter e pronto! 🎬

---

## 💡 Dicas de uso

- Use em um monitor grande ou TV para melhor leitura  
- Aumente o zoom do navegador se quiser letras maiores  
- Ideal para criadores de conteúdo e apresentações
